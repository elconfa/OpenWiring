# 20. Горячие клавиши, файлы и проблемы

## Горячие клавиши

В Windows вместо **⌘** используется **Ctrl**. Все сочетания кратко перечислены в окне *Справка ▸ Горячие клавиши и информация*.

| Клавиша | Действие |
|---|---|
| **W** | рисовать провод |
| **R** | повернуть выделение или вставляемый символ |
| **F** | вписать страницу в окно |
| **Del**, Backspace | удалить выделение |
| **Esc** | завершить текущую команду |
| **Стрелки** | сдвинуть выделение на 4 мм (с ⇧ на 16 мм) |
| **PageUp**, **PageDown** | предыдущая, следующая страница |
| ⌘Z, ⇧⌘Z (Ctrl+Y) | отменить, повторить |
| ⌘C, ⌘X, ⌘V | копировать, вырезать, вставить (в том числе в другой проект) |
| ⌘D | дублировать выделение |
| ⌘A | выделить всё на странице |
| ⌘F | найти и заменить |
| ⌘S, ⇧⌘S, ⌘O | сохранить, сохранить как, открыть |
| ⌘P | печать |
| ⌘I | открыть или закрыть ИИ-ассистента |
| Колесо мыши | масштаб вокруг курсора |
| Средняя кнопка, **Alt** + перетаскивание | сдвиг вида |
| **Shift** + щелчок | добавляет элемент в выделение или убирает его |
| Правая кнопка | контекстное меню; при вставке завершает команду |

## Файлы

| Расширение | Содержимое |
|---|---|
| `.ecad` | проект OpenWiring: страницы, элементы, настройки, использованные артикулы и символы, в читаемом файле JSON |
| `.ecmacro` | макросы для обмена |
| `.edz`, `.xml`, `.csv` | артикулы производителей (пакеты EDZ, XML в формате EPLAN, CSV коммерческих данных) |
| `.elmt`, `.qet` | компоненты QElectroTech |
| `.pdf` | схемы и списки; также как источник для импорта из других САПР |
| `.dxf` | страницы, монтажная плата со сверлением, импортируемые основные надписи |
| `.xlsx`, `.csv` | списки, устройства, переменные ПЛК, этикетки, словарь |
| `.txt` | страницы в текстовом формате |

**Личная библиотека** (артикулы, импортированные символы, макросы, основные надписи, шаблоны проектов) хранится
в программе на этом компьютере. Элементы, использованные в проекте, копируются в файл `.ecad`, поэтому
проект открывается полным и на другом компьютере.

## Частые вопросы

**Провод выглядит подключённым, но проверка говорит, что это не так.**
Провод проходит поверх точки подключения, не заканчиваясь на ней. Перетащите конец провода на точку
или удалите провод и нарисуйте заново, закончив его на точке (зелёный кружок).

**Два провода пересекаются: они соединены?**
Нет, если нет точки соединения. Чтобы соединить их, закончите один провод на другом.

**Контакт не показывает ссылку на катушку.**
У контакта должно быть то же обозначение, что и у катушки. Проверьте обозначение в свойствах контакта.

**Я добавил компонент, и номера проводов изменились.**
Так бывает при *пересчитываемой* нумерации. При *зафиксированной* (по умолчанию) существующие номера не меняются.

**Номер провода меняется после клеммы.**
В свойствах клеммы проверьте *Номер провода ▸ Номер провода проходит*.

**Межстраничная связь показывает красное `/?`.**
На другой странице нет парной связи с тем же именем.

**В PDF нет списков.**
Отметьте *Списки в конце* в окне PDF или создайте страницы списков.

**Приложение на macOS не открывается.**
См. [Установка](01-introduzione.md#macos): *Настройки ▸ Конфиденциальность и безопасность ▸ Всё равно открыть*.

**ИИ-ассистент отвечает «Доступ к учётной записи истёк».**
Выполните в Терминале указанную команду (например `codex login`) и повторите попытку.

**Импортированный компонент QElectroTech не работает.**
Вероятно, сохранена веб-страница GitHub вместо файла: скачивайте через *Raw*.

**Я потерял работу после внезапного закрытия.**
При повторном открытии программа предлагает последний проект, над которым вы работали. Тем не менее сохраняйте чаще с помощью ⌘S.
