# 1. Введение и установка

## Что такое OpenWiring

OpenWiring — это электротехнический CAD: в нём чертят не линии, а **соединённые устройства**. Программа знает, что контакт `-2K1 13-14` принадлежит катушке `-2K1`, что два провода, соединённые точкой, — один и тот же проводник, а клемма `-X1:3` передаёт провод `1.06` на двигатель. Из этих сведений она сама получает:

- **перекрёстные ссылки** между катушками и контактами, в том числе между разными страницами;
- **номера проводов** и их расположение на схеме;
- **списки**: спецификацию материалов, список закупки, списки устройств, клемм, соединений, проводов, кабелей, входов-выходов ПЛК;
- **проверку** проекта: короткие замыкания, пропущенные соединения, повторяющиеся обозначения;
- **экспорт**: PDF с интерактивными ссылками, DXF, Excel для TIA Portal, этикетки для принтеров.

Понятия те же, что приняты в промышленном электрическом черчении: обозначения IEC 81346, сетка 4 мм, страницы A3 с 10 колонками, ссылки вида `/страница.колонка` — и всё это в простом интерфейсе.

## Установка

Программа скачивается со страницы **Releases** проекта на GitHub (<https://github.com/elconfa/OpenWiring/releases>).

| Система | Какой файл скачать |
|---|---|
| macOS с процессором Apple (M1, M2, M3, M4) | `OpenWiring-x.y.z-arm64.dmg` |
| macOS с процессором Intel | `OpenWiring-x.y.z.dmg` |
| Windows 10 и 11, с установкой | `OpenWiring.Setup.x.y.z.exe` |
| Windows, без установки (один файл, можно с USB-флешки) | `OpenWiring-x.y.z-portable.exe` |
| Windows, без установки (папка) | `OpenWiring-x.y.z-win.zip` |

### macOS

1. Откройте файл `.dmg` и перетащите **OpenWiring** в папку *Программы*.
2. Один раз откройте приложение: появится предупреждение «Apple не может проверить…», потому что приложение не подписано платным сертификатом Apple. Закройте предупреждение.
3. Откройте *Системные настройки ▸ Конфиденциальность и безопасность*, прокрутите вниз, нажмите **Всё равно открыть** и подтвердите. В macOS 14 и более ранних достаточно щёлкнуть приложение правой кнопкой ▸ *Открыть* ▸ *Открыть*.

> **Если появляется сообщение «OpenWiring повреждён»** (версии до 0.14.0): откройте Терминал, выполните `xattr -cr /Applications/OpenWiring.app` и снова откройте приложение.

### Windows

Распакуйте zip в папку (например, *Документы\\OpenWiring-app*) и запустите `OpenWiring.exe`. В синем окне SmartScreen выберите *Подробнее ▸ Выполнить в любом случае*.

### Язык интерфейса

При первом запуске программа использует язык системы, если это итальянский, английский, французский, немецкий, испанский или русский. Язык можно изменить в любой момент через *Вид ▸ Language · Lingua*. Язык схем (основные надписи, списки, PDF) — отдельная настройка: см. [главу 16](16-lingue.md).

## Первый запуск

При первом запуске открывается **учебный проект** «Пуск двигателя насоса» — шесть готовых страниц для изучения:

| Страница | Содержание |
|---|---|
| 1 | силовая часть: автомат защиты двигателя, контактор, клеммник, кабель и двигатель; блок питания 24 В |
| 2 | управление: аварийный останов, пуск с самоподхватом, лампы |
| 3 | входы и выходы ПЛК |
| 4 | обзор модуля ПЛК, создаётся программой |
| 5 | сетевая схема Profinet и Modbus между двумя шкафами |
| 6 | однолинейная схема силовой части |

Его можно открыть снова в любой момент через *Файл ▸ Загрузить пример проекта*; *Файл ▸ Новый проект* начинает с пустой страницы.

## Сохранение работы

- **Сохранить** (⌘S) записывает проект в файл `.ecad`. *Сохранить как…* (⇧⌘S) создаёт копию.
- **Открыть** (⌘O) открывает файл `.ecad`. Файл содержит всё: страницы, настройки, используемые символы и артикулы.
- Программа также хранит **автоматическую копию** последнего открытого проекта и предлагает её при следующем запуске: это страховка на случай внезапного закрытия, но не замена команды *Сохранить*.
- В строке состояния внизу показано имя файла и точка `•`, если есть несохранённые изменения.

## Отмена

Любое изменение отменяется клавишами **⌘Z** (*Правка ▸ Отменить*) и повторяется клавишами **⇧⌘Z** (Ctrl+Y в Windows). Можно отменить до 100 шагов, в том числе крупные операции — например, применение страниц, написанных ИИ-ассистентом, или групповое изменение многих устройств.
